# Changelog

## v0.1.2

- 优化最终输出协议：默认输出可拍成稿，减少冗长中间过程。
- 加强口播脚本字数、节奏和 3 秒钩子的硬约束。
- 增加 Markdown 表格列数一致性要求。
- 技术类架构设计增加“最小实现方式”和“能力边界”要求。
- 分镜输出增加轻量版拍摄建议，降低普通创作者执行成本。
- 收敛标题党和过度营销表达。


## v0.1.0

- 初始纯 Skill 版本。
- 支持 technical、general_knowledge、product_marketing、career_experience、paper_to_video 五类。
- 每类采用 7 步提示词流程。
- 增加统一输出协议。
- 增加反馈模板和 GitHub Issue 模板。
