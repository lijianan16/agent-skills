## 强制要求

- 只输出上述 Markdown 内容。
- 不要在回复末尾追加 JSON。
- 不要输出 `<skill_result_json>`、XML 标签或代码块形式的结构化结果。
- Markdown 表格必须列数一致；如果无法保证列数一致，改用无序列表。
- 口播脚本必须符合目标时长，宁短不长。
- 如果生成失败，直接用 Markdown 说明失败原因和需要补充的信息。
- 如果只完成部分内容，直接用 Markdown 标明已完成部分和未完成原因。
