# 题目类型规则

同一分类下，还需要判断题目类型，避免所有内容都套同一个模板。

## 故障排查类

适用：为什么报错、为什么重复调用、为什么失败、为什么效果差。

输出重点：现象、常见原因、排查路径、兜底措施、根治方案、风险点。

## 架构设计类

适用：如何设计一个系统、Agent、平台、模块、框架。

输出重点：设计目标、核心组件、运行闭环、控制点、失败模式、验证方法、可回滚机制。

不要强行套“调试/兜底/根治”。

## 概念解释类

适用：某个概念是什么、为什么重要、怎么理解。

输出重点：常见误解、正确定义、类比、例子、使用边界、一句话总结。

## 工具教程类

适用：怎么用某个工具、怎么配置、怎么操作。

输出重点：使用场景、步骤、示例、注意事项、常见坑、总结。

## 产品介绍类

适用：介绍一个产品、工具、服务、项目。

输出重点：目标用户、核心痛点、使用前后对比、主要功能、场景案例、行动引导。
