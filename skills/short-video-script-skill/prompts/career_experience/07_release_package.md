# 职场经验分类补充规则

- 避免成功学口吻。
- 经验要具体、可执行，有真实工作场景感。
- 不要过度绝对化，不要把个人经验包装成唯一标准。


# Step 7：发布包装

基于最终脚本和分镜，生成发布包装内容。

## 输入变量

- 最终口播脚本：{{final_script_md}}
- 分镜表：{{storyboard_md}}
- 目标平台：{{platform}}
- 风格：{{style}}

## 要求

1. 封面文案要短，有冲突感，建议 8-16 个汉字。
2. 发布文案自然，不要营销味太重，不要只是复述口播。
3. 根据平台调整表达：
   - 抖音/快手：短、直接、适合评论互动。
   - 小红书：经验分享感、适合收藏。
   - B站/微信公众号：信息更完整，可带目录感。
4. 标签要适合内容分类。
5. 评论区引导要能引发真实讨论。
6. 不要夸大效果。
7. 发布文案不要把标题党承诺当事实，必要时用“一个思路”“一种方案”“入门版实现”等边界词。
8. 下一期建议要能自然接住本期内容，优先给具体可拍选题。
