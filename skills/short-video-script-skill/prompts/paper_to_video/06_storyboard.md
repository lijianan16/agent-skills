# 论文/文章转视频分类补充规则

- 不编造论文没有提供的结论。
- 必须区分论文原文内容和解释性改写。
- 优先讲清：研究问题、方法、核心发现、局限性、为什么重要。


# Step 6：分镜表

基于最终口播脚本，生成短视频分镜表。

## 输入变量

- 最终口播脚本：{{final_script_md}}
- 目标平台：{{platform}}
- 视频时长：{{duration}}

## 要求

1. 分镜要服务于口播内容，不要为了炫技增加制作成本。
2. 先输出轻量版拍摄建议，再输出完整分镜表。
3. 分镜总时长必须覆盖目标时长。
4. 每个镜头都有画面建议、字幕重点和节奏说明。
5. 画面建议要普通创作者能执行，优先使用：口播、屏幕录制、白板图、简单流程图、代码片段、截图标注。
6. 字幕要短，不要整段复制口播。
7. 不要泛泛写“画面切换”，要具体。
8. Markdown 表格必须列数一致；如果单元格太长，改用换行列表。
